# Portofolio Mahasiswa

Situs statis (HTML, CSS, JS), tanpa build dan tanpa dependensi. Status: **draft tanpa arah desain**, semua isi masih placeholder.

## Yang perlu Anda ganti
1. `js/data.js`: nama, angkatan, perkenalan, skill, email, tautan, dan ketiga proyek. Semua tanda `[ ... ]` adalah placeholder.
2. `assets/logo.svg`: ganti dengan logo Anda (nama file sama, atau ubah rujukan di `js/main.js` dan tiap `.html`).
3. `assets/foto-placeholder.svg`: ganti dengan foto Anda dan sesuaikan `src` di `index.html`.
4. Tambah atau kurangi proyek dengan menyalin satu blok di `PROJECTS`. `id` harus unik.

## Cara publikasi lewat GitHub Pages
1. Buat repositori baru di GitHub, lalu unggah **isi** folder ini (bukan folder induknya).
2. Buka Settings, Pages, pilih branch `main` dan folder `/ (root)`, lalu Save.
3. Alamat situs muncul di halaman itu setelah satu atau dua menit.

Uji lokal: buka `index.html` di browser. Formulir kontak membuka aplikasi email lewat `mailto:`, jadi tidak butuh server.
